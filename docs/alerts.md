# Alerting

## Sentry

Configure project alerts for new issues, error-rate spikes, and transaction latency regressions after `SENTRY_DSN` is set.

## Cloudflare

Enable notifications for Pages deploy failures, Worker exceptions, D1 errors, and high 5xx rates.

## Internal Health

Use uptime checks against the homepage, `/api/openapi.json`, runner negotiation, and Discord interactions endpoint signature validation probes.
